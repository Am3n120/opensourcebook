# Working it out on screen

For algebra, arithmetic and anything where symbols move, the strongest videos keep every symbol as a thing with an identity, so the viewer sees where each value comes from and goes. What tends to work:

- **A thing keeps its id.** When the same value appears in a later state, give it the same id and it travels there; the viewer sees where it came from. A value that becomes something else gets a new id. With `math`, `states=[...]` and `do become` move the symbols that stay.
- **Nothing is removed while it is still needed.** What a step depends on stays until it has been used; things leave when they are finished with.
- **It is there before the voice uses it.**
- **One change at a time, with the voice.** A new state whenever the voice moves to a new piece, often every 1 to 3 seconds; when the narrator reads numbers one after another, light each as it is said (`light`, `tag`, `mark ring`).
- **The given stays.** In a worked example the given problem can stay small at the top, so every number's source is visible. When a value is used in a new place while its source must stay, a copy with a new id lit together with its source shows the link.
- **Write the calculation as it is said,** piece by piece, ending in the result; the result can then replace the working so the frame stays clean.
- **A general rule gets its symbols too,** built up as the voice explains it, with the change happening on it. Words alone leave the screen empty when the viewer needs it most.
- **Every value says what it is.** "Dx = -11", not a bare -11.
- **Uncluttered.** A phone frame holds about six short lines.
- **Notation that is right.** Fractions as fractions, roots over what they cover, multiplication as ×, negative numbers in parentheses when they follow an operator: `math` sets all of this for real.
- **Numbers on screen that should add up do add up as shown.** A viewer checks the sum; angles worked out by a program and rounded each on its own can read 25 + 74 + 80, which is 179, in a video about 180. Pick values that are whole to begin with, or round so the shown parts make the shown total.
- **A sequence of examples is read, not glanced at.** Each example the viewer is meant to check stays long enough to check (a second or two per number), or it is one example held, with the others only suggested.
