Open Sourcebook

Understand what you have to read, and explain what you know. Turn your PDFs, notes, slides and reports into explainer videos, flashcards, quizzes, audio and guides, on your own computer, with the AI subscription you already have: Claude, ChatGPT, Gemini, Cursor or GitHub Copilot.

Free and open source.

Install it with one line

Open Sourcebook is installed on a computer. Open this page on your Mac, Windows or Linux computer and use the line there. The Mac line is shown below.

On a Mac

curl -fsSL https://opensourcebook.app/install | sh

  1. Open Terminal: press Command and Space, type Terminal, and press Return.
  2. Paste the line into the window that opens and press Return.
  3. Wait. The first time takes a few minutes. When it is done, your browser opens on Open Sourcebook.

On Windows

irm https://opensourcebook.app/install.ps1 | iex

  1. Open PowerShell: press the Windows key, type PowerShell, and press Enter.
  2. Paste the line into the window that opens and press Enter.
  3. Wait. The first time takes a few minutes. When it is done, your browser opens on Open Sourcebook.

On Linux

curl -fsSL https://opensourcebook.app/install | sh

  1. Open a terminal.
  2. Paste the line and press Enter.
  3. Wait. The first time takes a few minutes. When it is done, your browser opens on Open Sourcebook.

What the line does

  • It uses the Node 24 you already have. If you have none, it keeps a private copy of its own and leaves the rest of your computer as it is.
  • It downloads Open Sourcebook into one folder, .opensourcebook in your home folder.
  • It gets ffmpeg, which videos need, if you do not have it.
  • It never asks for your password or for administrator rights.
  • It changes nothing else. Outside that folder it adds only the opensourcebook command and a shortcut to open it. The first start also downloads the browser that videos are drawn with, once, into your computer's own cache folder.
  • Deleting that folder removes Open Sourcebook, and your projects with it.

Read the script first: the one for Mac and Linux, the one for Windows.

Starting it again

Type opensourcebook in Terminal or PowerShell and press Return. Or open Open Sourcebook from Applications on a Mac, or from the Start menu on Windows.

What you need

  • A Mac, Windows or Linux computer.
  • An AI subscription with its agent: Claude, ChatGPT, Gemini, Cursor or GitHub Copilot. An API key works too. Open Sourcebook has buttons that install the agent and sign it in for you.

Open Sourcebook is early. It has been tried most on a Mac, and Windows is the least tried.

Other ways

If you already have Node 24:

npx opensourcebook

If you want to change Open Sourcebook itself, get the code from github.com/Mikiyas-Meles-Assefa/opensourcebook:

git clone --depth 1 https://github.com/Mikiyas-Meles-Assefa/opensourcebook.git
cd opensourcebook
npm start
